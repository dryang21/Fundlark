# Verifying a funding opportunity

Treat these as separate questions:

| Question | Evidence needed |
| --- | --- |
| Does the program exist? | Official funder/program page or official API record. |
| Is this round accepting applications? | Current call dates, explicit open/closed statement, and relevant amendments. |
| Does the research fit? | Call topics and exclusions, compared with the user's actual project. |
| Can this person apply? | Individual/institution rules, career stage, geography, citizenship where relevant, host requirements and PI restrictions. |
| What support is offered? | Explicit award amount, currency, duration, and whether cash, compute, hardware, or credits. |

Prefer the funder's own page or call document over aggregators, university
research-office digests and news posts. When they disagree, report the funder's
date and say which secondary source conflicts. If the funder's page cannot be
reached, keep the lead under "requirements to confirm" rather than quoting the
secondary date as fact.

Do not convert missing deadlines into “rolling.” Use rolling only when the official
page explicitly accepts applications continuously. Keep forecasted calls separate.
A recurring program's past round does not establish the next deadline.

Record the exact deadline and timezone when given. If the page says only a date,
report that the time/timezone remains unspecified. A passed explicit deadline
overrides an old snapshot's open label. If sources conflict, disclose the conflict
and use the latest governing official announcement/amendment where identifiable.

Record the official URL, check date, call identifier/round, the page section
supporting a claim, and unresolved details. A concise paraphrase is sufficient;
do not copy entire announcements.

Eligibility labels can be:

- **Potential fit:** available facts align with the relevant published rules;
  explain unknown criteria rather than claiming definitive eligibility.
- **Faculty/institution route:** a qualified PI or institutional submission is
  needed. Check whether junior researchers can actually participate.
- **Unclear:** official evidence or user context does not settle a material rule.
- **Mismatch:** an explicit rule conflicts with a known applicant fact.

Do not infer nationality from location or a person's name. A postdoc title is not
proof of faculty PI eligibility. A resident is not automatically eligible for a
postdoctoral scheme. Research relevance and eligibility require separate reasoning.

Without browsing, provide a dated offline assessment of supplied materials. State
that availability has not been refreshed. Do not stamp a new “verified” date merely
because a public snapshot was downloaded today.
