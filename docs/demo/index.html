    Already use Codex or Claude Code? Add automatic contributions

    The optional Fundlark skill adds a repeatable verification workflow and can contribute public funding discoveries when you enable sharing. This requires a compatible agent with web and HTTP tools.

    Download the optional skill ↗
    1. Download and unzip the skill.
    2. Copy the fundlark folder into ~/.agents/skills/ for Codex or ~/.claude/skills/ for Claude Code.
    3. Start a new session in that app.

    Checking whether contributions are available…

    Contributions exclude your profile, CV and chats. We review public funding records before sharing. Changes apply to newly copied requests; they cannot revoke a request already pasted into another assistant.

    Fundlark does not open your assistant or search the web automatically. Your agent can use only the context its platform makes available.
