# Fundlark v4.4 — Combined research description and keyword editor

## User experience

* Step 1 uses **one** optional long-form research description for background, expertise and the project the researcher wants to fund. The previously separate background and project fields are gone.
* Extracted keywords appear directly **below the description**. Each keyword is a removable button with its source (`extracted` or `added`).
* Researchers can enter additional topics in the adjacent **Add keywords** field (comma separated), press Enter, or use example topic buttons.
* When a keyword is removed it remains excluded if the description is edited and after the profile is reloaded. **Restore extracted terms** clears exclusions. Adding a removed keyword manually also re-enables it.
* Automatically correct high-confidence misspellings in the **derived research keywords**, such as `reinforcment` → `reinforcement`. The original research description remains unchanged and a correction note explains what Fundlark normalized. Unknown technical names, mixed-case model names and acronyms are preserved.
* Keywords used in the personalized matching engine are the same edited, corrected list visible in Step 1 (maximum 20). Corrections are conservative and may miss typos; Fundlark does not perform grammatical rewriting or use a hosted AI text model.
* Existing saved research background and proposed project text is joined into the single editor when upgrading. Saved career stage, institution, eligibility details and memberships remain intact.
* Step 2 continues to separate scientific relevance from applicant eligibility. Step 3 remains an independent general search with 10 results per page. The bundled funding catalog is unchanged.

## Implementation details

Relevant files: `docs/demo/index.html`, `docs/demo/demo.js`, `docs/demo/manual-profile.mjs`, `docs/demo/matching.mjs`, `docs/demo/styles.css`, `tests-js/keyword-editor-v44.test.mjs`.

`buildResearchKeywords()` takes the single description, explicitly supplied keywords and an exclusion list. It applies curated spelling fixes and a conservative dictionary-based single-/two-character edit check, builds topic phrases from the existing matcher, removes weak generic single words and exclusions, and returns both the final list and correction evidence. The final list is the sole source of `profile.topics` for personalized matching.

## Limitations

This is *keyword* correction, not general autocorrect or grammar checking for arbitrary prose. High-confidence terminology corrections are applied in matching terms; users' original sentences are retained exactly. The lightweight local spelling rules may under-correct niche terminology or need new vocabulary added as disciplines expand. Official eligibility and deadlines remain subject to sponsor verification.
